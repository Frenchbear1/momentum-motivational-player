# Momentum

A distraction-free motivational video player built around local MP4 files.

- Starts from the first clip on every visit
- Plays 23 clips continuously with quick crossfades
- Preloads the next clip for smoother transitions
- Uses invisible full-height left and right tap zones for navigation
- Adapts naturally to portrait and landscape screens
- Keeps YouTube controls, ads, and branding out of the experience

The app is a static site. GitHub Pages publishes the contents of `dist/` through the included deployment workflow.
